# **App Name**: ZeitScan

## Core Features:

- Static QR Code Provisioning: Generate and provide a unique, static QR code (e.g., for print) that employees will scan to initiate their clock-in/out process, linking to the application's external time booking portal.
- Employee External Portal Webview: Provide an in-app webview for employees, accessible after scanning the QR code, to interact with the external time-booking website for name selection and confirming clock-in/out.
- Time Logging Backend: Implement robust backend logic to accurately record and store employee clock-in and clock-out events based on interactions with the external booking portal.
- Admin Dashboard for Time Management: A secure web-based dashboard for administrators to view, filter, search, and manage all recorded employee time logs, including timestamps and employee details.
- User Authentication & Authorization: Secure login mechanisms for both employees (basic access) and administrators (full dashboard access), ensuring data privacy and operational integrity.
- AI Assistant for Log Insights: An AI tool integrated into the admin dashboard to generate brief summaries of employee work patterns or highlight unusual clock-in/out activities, such as potential discrepancies or frequent short shifts.

## Style Guidelines:

- Primary action color: A professional and trustworthy mid-tone blue (#2663D9) to denote interactions and key information.
- Background color: A very light, clean bluish-gray (#E8EAEF) for a sense of calm and clarity, aligning with the light color scheme.
- Accent color: A brighter, contrasting cyan-blue (#149CB8) to draw attention to important elements, notifications, and interactive components.
- Body and headline font: 'Inter' (sans-serif) for its modern, clear, and objective aesthetic, ensuring high legibility for time logs and application text.
- Use minimalist, clean line icons that convey their meaning instantly for actions like scanning, time recording, and reporting within a professional context.
- Implement a clear and responsive layout, prioritizing mobile access for employees and offering a well-organized, data-rich experience for administrators on larger screens.
- Subtle and functional animations to provide visual feedback for actions such as a successful QR scan or data updates in the admin dashboard.
